# SOLIDWORKS 文件检索 1.2.0 使用说明

## 搜索

软件仅搜索 `.SLDPRT` 和 `.SLDASM`。顶部可选择文件名、属性或全部模式，并独立开关零件和装配体两类文件。Everything 可用时只负责加速文件发现；不可用时 Broker 自动使用内置限速扫描。

从旧式文件夹右键入口启动时，顶部持续显示“当前文件夹及子文件夹”和脱敏后的完整范围，可一键恢复全机搜索。路径范围不会保存成下次普通启动的默认值。

结果表的列宽、顺序、显隐和显示名都可调整；至少保留一列可见，可在设置的“结果列”页恢复默认。

## SOLIDWORKS Taskpane

安装包注册 SOLIDWORKS 2024 x64 CLR4 Taskpane 基线。设置中可对当前用户启停；SOLIDWORKS 已运行时需重启后生效。Taskpane 通过命名管道异步请求 Broker，SOLIDWORKS 进程内不运行 SQLite、索引、扫描或属性 Worker。

## 属性卡

资源管理器的 SOLIDWORKS 文件“查看属性”打开独立 PropertyViewer。它只通过 Broker 获取属性，并跟随“属性编写-拓创”的当前 `defaults.tsv` 设置：Base64 路径指向本机同步 XLSX。窗口按配置表中的模块、顺序、显示名和选项动态生成只读卡片；配置切换时配置特定值优先，同名文档属性只作回退。

活动表切换后会自动热更新。坏表或暂时不可达不会覆盖当前有效模型：先用 last-known-good，再用安装目录备用表。界面只显示“坚果云同步配置 (D:)”一类盘符级来源、更新时间和降级原因，不显示完整路径，也不读取浏览器、Cookie、Token 或凭据。未配置属性只在折叠诊断区显示，但仍保留在全属性搜索索引中。

## 设置

- 常规：Windows 登录启动。
- 搜索与索引：Everything 偏好、内置回退、网络根和后台暂停。
- 结果列：列布局、显示名和恢复默认。
- 集成：SOLIDWORKS Taskpane、文件夹菜单、开机自启的实时注册状态。

设置、SQLite schema v4 索引和日志默认位于 `%LOCALAPPDATA%\SwSearch`。Windows 11 新式一级文件夹菜单在本 RC 中因原生工具链与生产签名阻塞而不可用；Windows 10/旧式系统保留经典 verb。
